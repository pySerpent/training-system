## Описание проекта

Настольное приложение для Windows, предназначенное для автоматизации обучения и проверки знаний сотрудников в области информационной безопасности. Система позволяет вести учебные курсы, проводить тестирование с ограничением времени, анализировать результаты и выгружать протоколы проверок в форматы Word и Excel. В приложении реализовано разграничение прав доступа для трех категорий пользователей.

## Запуск из исходного кода

Требуется Python 3.11 или новее.

1. Клонируйте репозиторий:
   git clone https://github.com/pySerpent/training-system.git

2. Перейдите в папку проекта и создайте виртуальное окружение:
   python -m venv venv
   venv\Scripts\activate

3. Установите зависимости:
   pip install -r requirements.txt

4. Запустите приложение:
   python main.py

База данных `data/ib_training.db` уже лежит в репозитории с демонстрационными данными. Если файла нет, программа создаст его при первом запуске. Вернуть демонстрационный набор можно командой `python main.py --reset-demo`.

## Готовый exe

Скачать готовую сборку можно в разделе Releases: https://github.com/pySerpent/training-system/releases/tag/v1.0.0

Для самостоятельной сборки выполните скрипт `build_exe.bat`. Готовая программа появляется в папке `dist\IBTraining`, запускается файл `IBTraining.exe`.

## Автоматические тесты

Запуск из корня проекта:
python -m unittest discover -s tests -t . -v

Тесты работают с временной базой и рабочую базу не меняют.

## Возможности по ролям

- **Администратор:** управление пользователями и ролями, блокировка учетных записей, настройки системы (организация, логотип, тема, параметры тестирования), резервное копирование базы, журнал действий. Также доступен весь функционал преподавателя.
- **Преподаватель:** управление курсами и модулями, создание вопросов (одиночный и множественный выбор), импорт вопросов из Excel, назначение курсов подразделениям, просмотр результатов с комментариями, выгрузка протоколов в .docx и .xlsx.
- **Сотрудник:** просмотр материалов курсов, прохождение тестов, просмотр своих результатов и разбор ответов, личный кабинет со сменой пароля.

## Используемые библиотеки

- CustomTkinter: современный вид окон на основе стандартного Tkinter, светлая и тёмная темы, без внешних зависимостей от браузера.
- SQLAlchemy: работа с базой через классы-модели, без ручного SQL, с проверкой связей.
- python-docx и openpyxl: формирование протоколов в форматах Word и Excel без установленного Microsoft Office.
- Pillow: загрузка логотипа организации.
- hashlib, hmac, secrets (стандартная библиотека): хранение паролей в виде хеша.
